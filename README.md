## ✨ Как это работает?

Выбирайте и надевайте косметические предметы прямо
в инвентаре Dota 2.

Скины применяются только к вашему герою —
облик других игроков не меняется.

## 🚀 Как начать?

1. Скачайте и откройте AYSChanger.exe.
2. Если папка Dota 2 не определилась автоматически,
   укажите её в настройках.
3. Запустите игру через лаунчер и подождите 10–30 секунд.
4. Выбирайте предметы в инвентаре самой Dota 2.
